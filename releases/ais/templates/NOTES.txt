To launch Neurodesk notebooks from XNAT, set once in XNAT (Administer >
Plugin Settings > JupyterHub):
  JupyterHub API URL:  http://hub:8081/hub/api
  JupyterHub host URL: the hub's public URL
  JupyterHub token:    kubectl -n {{ .Release.Namespace }} get secret hub -o jsonpath='{.data.hub\.services\.xnat\.apiToken}' | base64 -d
and add a compute environment with the notebook image. Details: the neurodesk
chart's docs/xnat.md.
